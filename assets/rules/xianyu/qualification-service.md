# 闲鱼社区资质类商品与特定服务管理规范

## 第一章 总则

**第一条【目的】** 为规范资质类商品和特定服务的发布行为，保障用户权益，维护闲鱼社区交易秩序，制定本规范。

**第二条【适用范围】** 本规范适用于在闲鱼发布、销售资质类商品或者发布、提供特定服务的卖家。

**第三条【定义】** 本规范所称资质类商品，是指发布、销售时依法或者按照平台要求需提交行业资质或者商品信息资质的商品；特定服务，是指发布、提供时依法或者按照平台要求需提交服务资质证明的服务。

本规范所称“资质材料”，包括行业资质、商品信息资质和服务资质证明。

行业资质，是指依法经营特定行业或者类目应当取得的许可、备案、批准文件等证明。

商品信息资质，是指依法或者按照平台要求，在发布特定商品时应当提交、填写或者展示的认证、备案、批准、检测、追溯等信息。

服务资质证明，是指依法提供特定服务应当取得的职业资格、执业资格、岗位资格或者其他能力证明。

**第四条【具体要求】** 各类资质材料的适用范围、提交材料和信息要求，以本规范附表一《资质类商品发布要求》、附表二《特定商品信息填写要求》和附表三《特定服务发布要求》为准。附表是本规范的组成部分，法律法规或者监管政策另有规定的，从其规定。

## 第二章 卖家义务

**第五条【经营准入】** 卖家发布资质类商品或者特定服务前，应当按附表要求取得或者备齐相应资质材料，完成提交并通过平台审核。未取得、未备齐、未提交或者未通过审核的，不得发布相关商品或者服务。

**第六条【材料要求】** 卖家提交的资质材料应当真实、准确、完整、清晰；有有效期限的，应当在有效期内。不得伪造、变造、冒用、借用、租用、购买资质，或者以隐瞒、误导等方式规避审核。

**第七条【对应关系】** 资质材料应当与实际经营的商品、服务及其经营范围、地域、有效期限等相符。

**第八条【如实填写】** 卖家应当按照资质材料和商品、服务的实际情况，准确填写并展示平台要求的资质信息，不得夸大适用范围、虚构资质状态或者发布与资质不符的信息。

**第九条【持续维护】** 卖家应当持续关注资质状态。资质即将到期的，应当在到期前更新；资质记载事项发生变更，或者出现被撤回、撤销、吊销、注销、暂停使用等情形的，应当及时向平台更新或者说明。

**第十条【失效处置】** 资质过期、失效或者与实际经营不再相符的，卖家应当立即停止发布相关商品或者服务，并及时下架、删除或者调整相关信息。重新取得有效资质并通过平台审核后，方可恢复发布。

**第十一条【配合核验】** 平台审核、复核或者调查时，卖家应当在指定期限内补充、更新或者说明相关材料，并配合平台完成核验。卖家不得拒绝、拖延或者提供虚假材料。

**第十二条【信息保护】** 卖家提交资质材料时，不得遮挡平台要求核验的信息。平台按照最小必要原则收集、使用和保存资质材料；对外展示资质信息的，可视情况依法采取隐去、遮挡等保护个人信息的措施。

**第十三条【责任延续】** 资质失效、相关商品或者服务被处置，不免除卖家对已达成交易承担的履约、售后、退款、赔偿等责任。法律法规禁止继续履行的，卖家应当依法妥善处理未完结交易。

## 第三章 平台管理

**第十四条【平台审核】** 平台对卖家按附表提交的资质材料进行审核，并可以根据商品或者服务类型、风险程度和监管要求调整审核方式。平台审核不替代行政许可、平台认证或者专业判断，也不免除卖家依法应当承担的责任。

**第十五条【动态核验】** 平台可以通过定期复核、专项复核、抽查、信息比对、外部核验等方式，对资质状态及其与商品、服务的对应关系进行持续核验。基于监管通知、用户投诉、用户举报、交易纠纷、媒体报道、风险线索或者资质状态异常的，平台可以启动相关复核流程。

**第十六条【补正与临时措施】** 资质材料不清晰、不完整、信息不一致或者需要进一步核验的，平台可以通知卖家补充、更正或者重新提交，并载明要求、期限和逾期后果。

核验期间，平台可以根据风险程度，对相关商品或者服务采取限制发布、限制展示、暂停交易、下架、删除等临时措施。核验确认无误的，平台将解除相关临时措施。情况紧急的，平台可以先行采取措施，并及时通知卖家。

**第十七条【违规处置】** 卖家违反本规范的，平台可以根据违规性质、风险程度、影响范围及整改情况，采取审核不通过、删除或者下架相关信息、限制发布相关商品或者服务、限制相关经营权限、终止相关服务、扣分或冻结账号等措施。

平台采取对卖家有不利影响的措施时，将按平台规则告知相关事实、理由、依据和申诉途径。涉嫌违法犯罪的，平台可以依法向有关机关报告或者移送线索。

**第十八条【严重违规】** 有下列情形之一的，平台可以从重处置：

（一）伪造、变造、冒用、借用、租用、购买资质，或者以其他欺骗方式通过审核；

（二）明知资质过期、失效、被撤回、撤销、吊销、注销或者暂停使用，仍继续发布相关商品或服务的；

（三）拒不配合核验、逾期不整改，或者多次提交虚假、不合格材料；

（四）造成用户人身、财产损害，扰乱平台交易秩序，或者引发重大投诉、舆情及监管风险的；

（五）法律法规或者平台规则规定的其他严重情形。

**第十九条【恢复经营】** 卖家完成整改并提交有效资质材料后，可以按平台指引申请恢复相关商品、服务的发布权限。对于符合恢复条件的，平台将予以恢复；不符合的，平台将告知具体理由。

## 第四章 申诉

**第二十条【申诉】** 卖家对平台依据本规范采取的措施有异议的，可以在通知载明的期限内发起申诉，并提交真实、完整、有效的证明材料。平台将采取机器与人工结合的方式及时复核并反馈结果。申诉期间，不影响必要风险控制措施的执行。

## 第五章 附则

**第二十一条【规则衔接】** 用户除应遵守本规范外，还应遵守《闲鱼社区用户服务协议》、《闲鱼公约》及其他适用的平台规则。其他平台规则对特定商品或者服务的资质管理另有规定的，适用其规定。

**第二十二条【规则调整】**闲鱼可根据法律法规变化、监管要求、产品功能调整及社区治理需求，对本规范进行调整，并依法依规公示或者通知。调整后的内容于公示载明的日期生效。

**第二十三条【生效】**本规范于2026年11月1日首次生效。

### 附表一：《资质类商品发布要求》

| 资质类商品品类 | 具体发布要求 |
| --- | --- |
| **食品** | （一）食品生产商销售自产食品的，须提供营业执照和《食品生产许可证》；<br>（二）食品销售商须按照如下要求提交资质：<br>1、发布预包装/散装商品，须提供营业执照和《食品经营许可证》；<br>2、仅销售预包装食品的，可提供营业执照和《食品经营许可证》，或提交营业执照和预包装食品销售备案凭证；<br>（三）小规模食品生产经营者，须提供营业执照和《小作坊登记证》。 |
| **兽药** | 营业执照和《兽药经营许可证》 |
| **农药** | 营业执照和《农药经营许可证》 |
| **种子种苗** | 营业执照和《农作物种子生产经营许可证》或《林业种子生产经营许可证》；部分品种可提供备案登记（农作物种子备案登记/林业种子备案登记）；涉及种畜禽的，须提供《种畜禽生产经营许可证》 |
| **宠物医疗服务** | 营业执照和《动物诊疗许可证》 |
| **特种养殖类水族宠物** | 营业执照和《水生野生动物经营利用许可证》及/或《水生野生动物人工繁育许可证》 |
| **法律咨询服务** | 营业执照（经营范围含”法律咨询”）或《律师事务所执业许可证》或《基层法律服务所执业证》 |
| **律师诉讼委托服务** | 《律师事务所执业许可证》 |
| **专利代理服务** | 营业执照和《专利代理机构许可证》 |
| **商标代理** | 营业执照及商标代理机构备案证明 |
| **医疗/医疗咨询服务** | 营业执照和《医疗机构执业许可证》 |
| **旅行社服务（含旅游包车、签证、导游）** | 营业执照和《旅行社业务经营许可证》 |
| **驾驶技能培训** | 营业执照和《机动车驾驶员培训经营备案》 |
| **体育培训（高危险性项目：游泳、潜水、攀岩、滑雪等）** | 营业执照和《高危险性体育项目经营许可证》 |
| **图书** | 营业执照和《出版物经营许可证》 |
| **演出票务** | 营业执照和《营业性演出许可证》 |
| **开锁服务** | 营业执照和特种行业许可证或公安机关备案证明 |
| **检测服务** | 营业执照和《检验检测机构资质认定证书》（CMA） |

**注：平台将持续更新资质类商品的品类和具体要求，请以最新公示的版本为准。**

### 附表二：《特定商品信息填写要求》

| 特定商品品类 | 具体信息填写要求 |
| --- | --- |
| **食品/保健品类** | 预包装商品发布时，商品图片须包含食品标签的实物包装拍摄图，清晰展示食品名称、配料表、营养标签、净含量和规格、生产者及经营者的名称地址和联系方式、生产日期和保质期、贮存条件、食品生产许可证编号、产品标准代号、致敏物质提示等信息。<br>须如实描述商品的实际功效，食品产品、成分、功能、适用人群、检验认证、质量、执行标准等信息应真实、合法，不得含有虚假、夸大、引人误解的内容，不得涉及疾病预防、治疗等功效描述。普通食品宣称”绿色食品”“有机食品”等内容时，须在主图或详情页面展示清晰可辨认的认证证书，且认证证书应真实有效。<br>保健食品须展示有效的保健食品注册证书或备案凭证，商品描述须与注册/备案信息一致，不得宣称疾病预防、治疗功能。<br>婴幼儿配方乳粉须填写婴幼儿配方乳粉产品配方注册号；特殊医学用途配方食品须填写特殊医学用途配方食品注册号，并公示产品注册证书或者备案凭证。 |
| **图书类** | 发布图书类商品时，须填写商品的ISBN编号，ISBN编号须与实物商品一致。 |
| **化妆品类** | 化妆品商品须展示备案编号或注册证书编号，商品描述须与备案/注册信息一致。不得宣称医疗功效，不得使用虚假或引人误解的功效描述。 |
| **3C认证商品类** | 电动车、移动电源、厨房电器、消防器材等须3C认证的商品，发布时须在商品详情页展示有效的3C认证证书编号及认证标志。商品实际规格、参数须与认证证书载明信息一致。 |

**注：平台将持续更新特定商品的品类和具体要求，请以最新公示的版本为准。**
